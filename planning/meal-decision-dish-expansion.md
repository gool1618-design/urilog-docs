# ピクモグ 料理データの増やし方(2026-09-22)

料理 150 件(2026-09-21)→ 190 件(副菜 +30・汁物 +10、2026-09-22)。この文書は、この先どこから・どう増やすかの基準。

## 1. 方針(第3版から変えない)

- **料理名・材料名・絵は、すべて自分で用意した一次データ。** 外部サイトの料理一覧・写真・レシピを取得・転載しない(仕様 §6)。
  料理名そのものに権利はないが、特定のサイトの一覧を丸ごと写すと、そのサイトの編集の成果を写すことになる。**参考にしてよいのは「その料理が家庭の定番か」の裏取りだけ。**
- 作り方: **AI(Claude)が下書き → 机上で確認 → `check_dish_coverage.py` で網羅性を検証 → 絵は Codex で同じ型で量産 → Claude が全枚数を検品**。
  150 件の実績: 絵は 3 本並行で約 50 分、不合格 4%(→ `~/Documents/_ios/60_技術メモ.md`)。

## 2. 「質がいい」の基準(1 件ずつ確かめる)

| 基準 | 中身 |
| --- | --- |
| 家庭の定番か | 料理名を聞いて、たいていの人が見た目を思い浮かべられる。地方名・店の名前・創作名は入れない |
| 作れるか | 主菜は 30 分以内が中心(40 分は週末向けに少し)、副菜は 10 分前後、汁物は 15 分以内 |
| 材料が揃うか | 普通のスーパーで年中(季節ものは season を付ける)。主な材料は 3〜5 個 |
| 被らないか | 既存と同じ料理の言い換えにしない(「豚の生姜焼き」と「しょうが焼き」など) |
| 絵になるか | 1 皿で「その料理」と分かる。盛り付けで見分けがつかないものは避ける |
| データが正しいか | 形(1品完結 / 主菜 / 副菜 / 汁物)、系、気分、時間、手間、費用、除外食材(卵・乳・小麦・えび・そば・豚・鶏・牛・魚・豆腐・きのこ・ごま・大豆)、季節、無料/Pro |

## 3. 裏取りに使ってよい、質の高い情報源

写すのではなく、**定番度と分類の根拠**として参照する。

| 情報源 | 使いどころ |
| --- | --- |
| 農林水産省「食事バランスガイド」 | 主食・副菜・主菜の区分と料理例。**副菜(野菜・きのこ・いも・海藻の料理)の範囲を決める根拠**。「野菜を多めに」の判定にも使う |
| 農林水産省「うちの郷土料理」 | 全国に広まった家庭料理の季節もの(郷土色が強すぎるものは入れない) |
| 文部科学省「日本食品標準成分表」 | 材料名の表記をそろえる(「長ねぎ / ねぎ」など) |
| 総務省「家計調査」 | 季節ごとによく買われる食材 → season の付け方の根拠 |
| 各種の「よく作る夕食」調査(公開されている集計) | 定番度の確認に引用するだけ(一覧を写さない) |

## 4. これから増やす順番

1. ~~副菜 +30・汁物 +10~~(2026-09-22 済み。Pro の「献立のかたち(副菜付き)」で毎日付けても 1 か月は一巡しない)
2. **昼向けの軽い 1 品 +20**(麺・丼・パン系。「もう一食(昼)」で同じ料理ばかりにならないように)
3. **季節の主菜 +20**(春夏秋冬 5 件ずつ。season で出し分け)
4. **子ども向け・作り置き向けのタグ**(v1.2 の家族向け。料理を増やすより先にタグを検討)

- 増やすたびに `check_dish_coverage.py` を通す(気分 × 時間 × 除外食材で候補 3 件以上)。
- 無料 / Pro の比率は、無料で「決める」体験が完結することを優先して決める(副菜は Pro の機能で主に使うので Pro 多め)。
