# サッカー推し活アプリ 画面仕様

作成日: 2026年9月20日
前提: `soccer-fan-app.md` の決定事項に基づく。初期リリース(v1.0)の範囲を書く。Pro 機能は境界だけ示す。

---

## 0. 全体構造

```
[オンボーディング](初回のみ)
   └→ [タブバー]
        ├ ホーム
        ├ 日程          → 試合詳細(記録)
        ├ 振り返り      → 写真一覧 / 年間まとめ
        └ (歯車) 設定   → 各設定画面 / Pro
```

- タブは3つ。設定はホーム右上の歯車から開く。タブを減らすのは、推し活アプリとして「ホームに戻れば推しの色がある」体験を最優先にするため。
- 試合詳細(記録)は日程からもホームからも開ける同一画面。
- 複数チームは v1.0 では非対応。データ構造だけ `teamId` で分けておく。

### テーマ(チームカラー)

- 主色(primary)と副色(secondary)の2色。ホームの背景と、各画面のアクセント(ボタン、選択状態、タブの選択色)に使う。
- 文字色は主色の明度から自動で白か黒を選ぶ。コントラスト比 4.5:1 を下回る組み合わせは、背景を少し暗く(明るく)して確保する。
- ダークモードでは主色を背景に使わず、アクセントのみに使う。背景は標準の黒系。
- プリセットの色は主要クラブ分をアプリ内に持つ(名前と HEX のみ、ロゴなし)。無いクラブはオンボーディングで2色を選ぶ。

### 共通の入力ルール

- 保存ボタンは置かない。入力は即時に保存し、画面を閉じても残る(バイヤーノートと同じ)。
- 破壊的操作(記録の削除、推しチーム変更)だけ確認ダイアログを出す。
- テキスト入力は1行(一言)と複数行(メモ)を分け、一言は40文字程度で折り返さない。

## 1. オンボーディング(初回起動)

| 画面 | 内容 | 操作 |
|---|---|---|
| 1. ようこそ | アプリの一言説明(「推しチームとの思い出を積み上げる」)。データ提供元の表示(Data provided by TheSportsDB.com)。 | 次へ |
| 2. リーグを選ぶ | プロキシから取得した対応リーグ一覧(国旗は使わず国名テキスト)。取得できないときは「あとで選ぶ」で手動チーム作成へ。 | リーグをタップ |
| 3. チームを選ぶ | 選んだリーグのチーム一覧。検索欄あり。 | チームをタップ |
| 4. 色を決める | プリセットがあれば自動で2色を表示し、「この色でOK」。無ければカラーピッカーで主色・副色を選ぶ。プレビューにホームの縮小版を出す。呼び名(表示名)の編集欄。 | 決定 |
| 5. 通知 | 「前日の夜と、キックオフ1時間前にお知らせ」の説明と許可ボタン。「あとで」で飛ばせる。 | 許可 / あとで |
| 6. 完了 | 「次の試合は ○月○日 vs ○○」を推しの色で表示。 | はじめる → ホーム |

- 手動チーム作成(2で「あとで選ぶ」): 名前、2色、シーズン開始月を入力。日程は自動取得されず、すべて手動登録になる旨を表示。
- オンボーディング完了までデータは保存しない。途中終了したら次回は1からやり直し。

## 2. ホーム

推しの色で塗られた画面。上から順に:

1. **ヘッダー**: 呼び名(表示名)。右上に歯車。
2. **次の試合カード**(最も大きい)
   - 「あと ○日 ○時間」のカウントダウン(24時間を切ったら時間単位、1時間を切ったら分単位)。
   - 対戦相手、ホーム/アウェイ、大会名、キックオフ日時(端末のタイムゾーン)。
   - 試合中(プロキシのライブ情報で試合中、または情報が無ければキックオフから2時間半以内): 「試合中」バッジと、設定がオンならスコアと経過(前半・後半・○分)。小さく「約2分遅れ」。設定がオフなら「試合中」だけで、スコアは伏せる。
   - 試合終了後、記録がない: カードが「見た? 記録する」に変わる。1タップで試合詳細へ。
   - 次の試合が無い(シーズンオフ、データ未取得): 「次の試合はまだ決まっていません」+ 手動で追加ボタン。
3. **直近の結果**(1件): スコア、勝敗の色分け(勝ち=主色、負け=グレー、引き分け=副色)、自分の一言があれば表示。タップで試合詳細。
4. **順位の抜粋**: 推しチームの前後1チームずつ、計3行(順位、チーム名、試合数、勝点)。タップで順位表全体をモーダル表示。手動チームのときは非表示。
5. **推し選手の写真**: ユーザーが選んだ1枚を角丸で表示。キャプション(任意)。未設定なら「推し選手の写真を置く」プレースホルダ。
6. **今シーズン**: 観戦 ○試合 / ○勝○分○敗(自分が見た試合のみの成績)。タップで振り返りタブへ。

- 引っ張って更新で、プロキシから日程・結果・順位を再取得。
- 取得に失敗したときは画面上部に薄いバナー「最新のデータを取得できませんでした(最終更新 ○月○日 ○時)」。キャッシュは表示し続ける。

---

## 3. 日程

推しチームの試合だけを一覧にする。

- **セグメント**: 「これから」「これまで」。既定は「これから」。シーズン終盤で「これから」が空なら「これまで」を開く。
- **シーズン切替**: ヘッダーのメニューから過去シーズンへ。
- **大会フィルタ**: リーグ戦のみ / すべて(カップ戦、手動登録分を含む)。既定はすべて。
- **行のレイアウト**:
  - これから: 日付(曜日)、キックオフ時刻、相手名、H/A、大会の略称。試合中の行は「試合中」バッジ(設定がオンならスコアも)。
  - これまで: 日付、スコア(推し視点で「2-1 ○」のように勝敗記号を添える)、相手名、H/A、観戦方法のアイコン(現地=スタジアム、配信=再生、テレビ=TV、未記録=空欄)。一言があれば2行目に薄く。
- **行をタップ**: 試合詳細へ。
- **手動追加**(右上の +): 日付、時刻、相手名(入力履歴から候補)、H/A、大会名(任意)、会場(任意)。`source = manual`。
- **手動登録の試合と自動取得の試合の見分け**: 手動登録には小さな「手動」ラベル。
- **延期・中止**: 行に「延期」「中止」バッジ。カウントダウンの対象から外す。

---

## 4. 試合詳細(記録)

日程・ホームから開く。上から順に:

1. **試合情報**: 日付、時刻、大会、会場(あれば)、ホーム/アウェイ、スコア(自動取得の場合は編集不可の表示、右端の「修正」で手動上書き可。上書きした行は `manuallyEdited = true` で同期対象から外れる)。手動登録の試合はすべて編集可。試合中は設定に従ってライブスコアと経過を表示し、90秒ごとに更新する。
2. **観戦ステータス**(最初に触るところ。大きなセグメント):
   - 「現地」「配信」「テレビ」「見てない」の4択。未選択の状態が既定。
   - 選ぶと即保存。ホームの「見た?」が消える。
3. **視聴サービス**(観戦ステータスが配信/テレビのときだけ表示): チップ選択。既定の選択肢は DAZN、U-NEXT、ABEMA、SPOTV NOW、Apple TV、地上波/BS、その他。設定で編集可。
4. **一言**: 1行テキスト。プレースホルダは「一言だけでも」。
5. **写真**: 横スクロールのサムネイル + 追加ボタン。追加時に「観戦写真」「チケット」を選ぶ。無料は1試合5枚まで、Pro で無制限。上限に達したら追加ボタンが Pro 案内に変わる。
6. **もっと書く**(折りたたみ、既定は閉じている):
   - 満足度(1〜5の星)
   - 自分MVP(テキスト。入力履歴から候補)
   - 印象的な場面(複数行)
   - メモ(複数行)
7. **削除**(最下部、赤文字): 手動登録の試合は試合ごと削除。自動取得の試合は「記録だけ削除」(試合は残る)。

- 写真をタップで全画面表示、スワイプで切替、共有シートで保存や他アプリへ。共有は OS 標準の共有シートのみで、アプリ独自の SNS 連携は持たない。
- 「見てない」を選んだ試合は振り返りの観戦数に含めない。一言や写真は残せる(「見逃したけど一言」用)。

---

## 5. 振り返り

シーズン単位で自分の記録を集計する。

1. **シーズン切替**(ヘッダー)。既定は現在のシーズン。
2. **サマリーカード**(2列グリッド):
   - 観戦数(現地 / 配信+テレビ の内訳)
   - 観戦した試合の成績 ○勝○分○敗
   - 現地観戦数(会場の数)
   - 平均満足度(満足度を入れた試合があるときのみ)
3. **視聴サービス別の本数**(横棒)。
4. **月別の観戦数**(縦棒、シーズンの月数分)。
5. **写真**: 最新から並ぶグリッド。タップで全画面。「すべて見る」で写真一覧画面。
6. **ベストゲーム**:
   - 「今シーズンのベストゲームを選ぶ」ボタン。観戦した試合の一覧から1つ選ぶ。選ぶと大きなカードで表示(相手、スコア、一言、写真1枚)。
   - シーズンが終わると(最終節の翌日以降)、ホームにも「今シーズンのベストゲームを選ぼう」の案内を1回出す。
7. **年間まとめ**(Pro): 上の内容を1枚の画像にまとめて書き出す。無料はプレビューだけ。

- 通算(全シーズン)の表示はシーズン切替の一番上に「すべて」として置く。観戦数と成績だけを出す。

## 6. 設定

| 項目 | 内容 |
|---|---|
| 推しチーム | 現在のチームと色。「変更」で オンボーディング2〜4を再実行。変更しても過去の記録は元のチームに紐づいたまま残り、日程タブのシーズン切替から見られる。 |
| 推し選手の写真 | 写真ライブラリから1枚選ぶ。キャプション(任意)。「外す」。 |
| 観戦方法の選択肢 | 視聴サービスのチップを追加・削除・並べ替え。 |
| 通知 | 前日の夜(時刻を選べる、既定 20:00) / キックオフ1時間前 / なし。複数選択可。 |
| 試合中のスコア | 「試合中のスコアを表示」オン/オフ。既定はオン。説明文「約2分遅れで更新します。見逃し配信で見る日はオフにするとネタバレを防げます」。 |
| Pro | 年額 ¥1,200 / 生涯 ¥3,900。特典一覧。購入の復元。 |
| 書き出し | CSV(試合と記録)+ 写真を ZIP にして共有シートへ。 |
| データについて | 「試合データは TheSportsDB.com の提供です」。最終更新日時。「データを今すぐ更新」。 |
| サポート | プライバシーポリシー、利用規約、お問い合わせ(メール)、アプリのバージョン。 |

## 7. 通知(ローカル通知)

| タイミング | 文面の例 |
|---|---|
| 前日の夜 | 「明日 21:00 キックオフ: ○○ vs △△(アウェイ)」 |
| 1時間前 | 「あと1時間で ○○ vs △△」 |
| 試合終了の見込み時刻(キックオフ+2時間)| 「○○ vs △△ はどうだった? 一言だけでも残そう」(設定でオフにできる。既定はオン) |

- 通知は日程を取得したときに、直近30日分をまとめて再登録する(iOS の登録上限64件に収まる)。
- 延期・中止になった試合の通知は取り消す。

## 8. 無料と Pro の境界

| 機能 | 無料 | Pro |
|---|---|---|
| 推しチーム | 1 | 1(複数は将来) |
| 日程・結果・順位の自動取得 | ○ | ○ |
| 記録(一言、観戦方法、満足度、MVP、メモ) | ○ | ○ |
| 写真 | 1試合5枚 | 無制限 |
| 年間まとめの画像書き出し | プレビューのみ | ○ |
| ウィジェット | 次の試合(1種) | 追加スタイル(将来) |
| テーマの微調整 | プリセットと2色 | 将来 |
| 書き出し(CSV + 写真) | ○ | ○ |

- Pro の購入画面は「写真を6枚目に追加しようとしたとき」「年間まとめを書き出そうとしたとき」「設定の Pro」の3か所から開く。それ以外で割り込まない。

## 9. 空状態・エラー・オフライン

| 状況 | 表示 |
|---|---|
| 日程が1件もない(取得前) | 「日程を取得しています」→ 失敗したら「取得できませんでした。引っ張って再試行」 |
| オフライン | キャッシュを表示。ホーム上部に「オフライン(最終更新 ○時)」 |
| シーズンオフ | 次の試合カードに「次のシーズンの日程が発表されたら表示します」 |
| 手動チーム | 順位の抜粋を非表示。次の試合カードに「試合を追加」。ライブスコアは無し |
| ライブ情報が取れない(上流障害) | 「試合中」バッジのみ。スコア欄に「取得できません」 |
| 写真の参照切れ(推し選手) | イニシャルの円に戻す。設定で再選択を促す |

## 10. アクセシビリティと端末

- Dynamic Type に追従。カウントダウンの数字は最大サイズでも1行に収まるよう自動縮小。
- VoiceOver: スコアは「2対1、勝ち」のように読み上げる。観戦方法のアイコンにラベル。
- 対応 OS は iOS 17 以降(SwiftData のため)。iPhone のみ。iPad は将来。
- ウィジェット(小): 次の試合までのカウントダウンと相手名。推しの色。
